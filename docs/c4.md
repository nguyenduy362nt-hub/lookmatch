## Mức 2 – Container
```mermaid
flowchart LR
  subgraph Phone[Điện thoại nhân viên]
    APP[Flutter app\nchọn ảnh, hiển thị top-10]
  end
  subgraph Server[Docker host / AWS]
    API[FastAPI\n/health /search /catalog]
    EMB[Embedding module\nCLIP hoặc DINOv2]
    IDX[(FAISS Flat index\n+ metadata.json)]
    IMG[(Ảnh sản phẩm)]
  end
  APP -->|HTTPS multipart ảnh| API
  API --> EMB --> API
  API -->|search k=10| IDX
  API --> IMG
```
Luồng tìm: ảnh → resize → embedding (vector chuẩn hoá L2) → FAISS tìm 10 vector gần nhất theo cosine → trả mã sản phẩm + điểm + ảnh.
